# Demo 9 — Write an effective prompt

## Prompts
```
Create interview questions for a Sales Representative.
```
**It works... but did we give Copilot enough to work with? 😏**

Let’s give it some **context**.
```
I am a hiring manager preparing to interview a candidate for a Sales Representative position. Create a structured set of interview questions for the candidate.
```
**It’s better, but not quite there yet!**

Let’s give it some **sources**.
```
Use the attached job description to identify the responsibilities, qualifications, skills, and experience relevant to the position. Use interviewing tips from https://fitsmallbusiness.com/interview-tips-for-hiring-managers as a guide for creating questions.
```
Attach the file Tailspin_Toys_Sales_Representative_Job_Description.docx

Let’s share what our **expectations** are for the output.
```
Organize the questions into categories and include a mix of behavioral, situational, and role-specific questions. Keep the interview appropriate for a 30-minute conversation.
```
Let’s ask Copilot to take our entire interaction and put it into a single prompt, in case we want to run it again or share it.
```
Create single prompt from this entire interaction.
```
